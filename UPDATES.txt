Date:     2026-06-10
Commit:   uncommitted
Files:    codenames/codenames.go, w2v/w2v.go, llm/llm.go,
          cmd/ai-server/server.go, frontend/src/lib/game.svelte.ts
Summary:
  - AI operatives can now PASS (end the turn) instead of being forced to
    guess. The game engine and web API already supported passing (the
    human "End Turn" button uses it); this wires the AIs into it.
      * New codenames.PassGuess sentinel + GuessOrPass(board, clue,
        mustGuess) on both AI backends. mustGuess is true on the first
        guess after a clue (Codenames requires at least one guess), so
        AIs only pass on follow-up guesses.
      * An AI pass is a consensus vote like any other — on mixed teams
        humans still have to agree before the turn ends.
  - w2v guesser: passes when the best remaining word scores below a 0.15
    cosine-similarity threshold — no more wild low-confidence guesses.
  - LLM operative: on follow-up guesses the prompt offers "respond PASS
    if nothing fits or everything feels risky".
  - LLM spymaster is now risk-averse: prompt makes it check targets
    against opponent/bystander/assassin words and lower its count when
    uncertain ("Uncertainty = lower count").
  - Game history shows "(pass)" for passed turns.

Date:     2026-06-10
Commit:   fdd53a9
Files:    cmd/ai-server/server.go, llm/llm.go
Summary:
  - Added randomized human-like thinking delays to the AI server so bot
    response times no longer give them away in Turing test games:
      * Clues:   8-25 seconds
      * Guesses: 3-15 seconds
    Delay is measured from the start of the AI call, so slow LLM responses
    count toward the target instead of stacking on top. Applies to BOTH the
    w2v and llm backends.
  - Rewrote the LLM spymaster prompt to play more like a human:
      * Prefer clue counts of 2 or 3; only give 4+ when the connection is
        instantly obvious.
      * Favor intuitive, slightly creative, or cultural connections over
        the most statistically obvious one.
      * Added a self-check step: before answering, verify the clue is not
        associated with the assassin word in meaning, sound, or category.
  - Rewrote the LLM operative prompt to play more like a human:
      * Reason about what the spymaster INTENDED, not raw word similarity.
      * Prioritize the most obvious connection a person would see first.
      * Pick the safest, most direct word when several fit.
  - NOTE: "stop early / pass on risky guesses" was intentionally NOT added
    to the operative prompt — the game protocol has no pass action, so a
    refusal would trigger the random-guess fallback (more detectable, not
    less). Needs a protocol-level pass mechanism first (see to-do list).
